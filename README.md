Funbook - Social Media Platform
Funbook adalah platform media sosial yang dibangun dengan PHP, MySQL, dan Bootstrap. Aplikasi ini menawarkan fitur-fitur lengkap untuk terhubung dengan teman, bergabung dengan grup, dan berbagi konten.

🚀 Fitur Utama
👤 Sistem User
Registrasi & Login dengan autentikasi aman
Profil User dengan foto profil, cover photo, dan bio
Role-based Access Control (User, Admin)
Sistem Banned untuk user yang melanggar aturan

🤝 Sistem Pertemanan
Tambah Teman dengan sistem permintaan
Konfirmasi Permintaan pertemanan
Daftar Teman dengan filter
Saran Teman berdasarkan algoritma

📱 Fitur Postingan
Buat Postingan dengan teks, gambar, dan video
Upload Foto dengan preview otomatis
Upload Video dengan player HTML5
Sistem Like/Unlike postingan
Komentar pada postingan dengan reply
Feed Beranda dengan postingan terbaru
Video Player built-in untuk video upload

👥 Sistem Grup
Buat Grup baru
Bergabung dengan Grup yang ada
Kelola Anggota (Admin, Moderator, Member)
Tinggalkan Grup (kecuali admin)

⚙️ Admin Panel
Dashboard Admin dengan statistik
Kelola User (ban/unban, jadikan admin)
Hapus Postingan yang tidak pantas
Akses Cepat ke semua fitur admin

🛠️ Teknologi yang Digunakan
Backend: PHP 7.4+, PDO MySQL
Frontend: Bootstrap 5, Font Awesome
Database: MySQL 5.7+
Server: Apache (XAMPP/Laragon)
Security: Password hashing, SQL injection prevention
